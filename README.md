# 🧮 Kalkulator Penjumlahan Sederhana

Proyek web sederhana berbasis HTML, CSS, dan JavaScript untuk melakukan penjumlahan dua angka.

## 🚀 Fitur
- Input dua angka secara independen.
- Menghitung hasil penjumlahan secara instan.
- Desain *clean* dan *responsive*.
